# Mijn Eetboek 🍲

Welkom! Dit is de publieke plek van **Mijn Eetboek**, een gezellige, rustige
app voor je weekmenu, boodschappen en recepten. Gebouwd door één maker,
zonder poespas.

👉 **Probeer de app**: [mrsmime.github.io/eetboek-dev](https://mrsmime.github.io/eetboek-dev/)
